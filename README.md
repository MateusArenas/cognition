# cognition

Editor de diagramas Mermaid e documentos Markdown para celular (Expo/React Native), com uma
tab separada pra um cliente de banco de dados estilo DBeaver/TablePlus. Monorepo: o app fica
em [editor/](editor/), o backend do cliente de banco (NestJS) fica em [backend/](backend/).

Comece por [CLAUDE.md](CLAUDE.md) — descrição do produto, roteiro da documentação em
[docs/](docs/) e o progresso de build em [CHECKLIST.md](CHECKLIST.md). Cliente de banco em
detalhe: [docs/17-db-client.md](docs/17-db-client.md).
